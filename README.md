# Название проекта
**Разработка ИИ–тренера по лечебной физкультуре**

## Краткое описание
Программа представляет собой прототип персонального ИИ-тренера для контроля правильности выполнения упражнений лечебной физической культуры (ЛФК). Система в реальном времени через веб-камеру или из видеофайла анализирует позу пользователя, вычисляет биомеханические параметры (углы в суставах, амплитуду, симметричность нагрузки) и выдаёт текстовые рекомендации по коррекции техники. Поддерживаются три упражнения: «Подъём на носочки», «Отжимания от пола», «Полуприсед». Результаты тренировки сохраняются в CSV-файл для последующего анализа.
